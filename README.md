# Pasta Bella - Restaurante de Pasta Italiana 🍝

Aplicación frontend para un fino restaurante de pasta italiana, construida utilizando **React y Vite**. Incluye una *landing page* promocional, visualización del menú de ofertas y paneles administrativos (CRUD) funcionales para la gestión de usuarios, delivery y pedidos en sala, todos implementando diseño UI/UX moderno y modo oscuro (Glassmorphism).

🌍 **Mira el despliegue en vivo aquí:**  
👉 [https://restaurante-pasta-italiana.onrender.com/](https://restaurante-pasta-italiana.onrender.com/)

---

## ✨ Tecnologías utilizadas
- React + Vite
- React Router DOM
- CSS Puro (Vanilla CSS moderno)
- Lucide React (Íconos)
- Diseño responsivo

## 👨‍💻 Pasos para clonar y ejecutar localmente

Si deseas probar o modificar este proyecto en tu propia máquina, sigue estos pasos:

### 1. Clonar el repositorio
Abre tu terminal y trae el código ejecutando:
```bash
git clone <URL_DE_TU_REPOSITORIO>
```
*(Copia y pega la URL de clonación desde tu rama de GitHub, o descárgalo como ZIP y extráelo).*

### 2. Entrar a la carpeta del proyecto
```bash
cd restaurante-pasta-italiana
```
*(Asegúrate que el nombre de la carpeta coincida con el directorio clonado).*

### 3. Instalar dependencias
Debes tener instalado [Node.js](https://nodejs.org/). Ejecuta el siguiente comando para instalar las librerías necesarias:
```bash
npm install
```

### 4. Lanzar el servidor de desarrollo
Finalmente, levanta el proyecto:
```bash
npm run dev
```

La terminal te mostrará un enlace local (usualmente `http://localhost:5173/`). Solo ábrelo en tu navegador y verás la aplicación corriendo de forma nativa.
